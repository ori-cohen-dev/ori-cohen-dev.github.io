# מענה אוטומטי להזמנת מנות

מערכת שעונה לטלפון בשעות קבועות, שואלת **איזו משפחה** ו**כמה מנות**, רושמת לגיליון גוגל, ובסוף כל יום שולחת לך לוואטסאפ רשימה:

```
הזמנות 24/11:
כהן – 4
לוי – 6
לא מזוהה 0504444444 (הקלטה: …) – 5
סה"כ: 15 מנות
```

**הכול חינם ובלי שרת משלך:** ימות המשיח (הטלפון) ← Google Apps Script (הלוגיקה + גיליון) ← CallMeBot (וואטסאפ) + מייל לגיבוי.

## איך השיחה עובדת
1. מחוץ לשעות/ימי הפעילות ← הודעה "המערכת פעילה בין…" וניתוק.
2. מתקשר **מוכר** (המספר שלו בלשונית "משפחות") ← "שלום משפחת כהן", ישר לשאלת המנות.
3. מתקשר **חדש** ← "אמרו את שם המשפחה אחרי הצליל" (הקלטה).
4. "כמה מנות?" ← הקשה (המערכת חוזרת על המספר לאישור). **0 = ביטול** ההזמנה של היום.
5. "נרשמו 4 מנות, תודה" וניתוק.

התקשרו פעמיים באותו יום? **ההזמנה האחרונה קובעת.**

---

## הקמה — צעד אחר צעד

### 1. גיליון + סקריפט
1. צור גיליון חדש ב-Google Sheets (למשל "הזמנות מנות").
2. בתפריט: **תוספים (Extensions) ← Apps Script**.
3. מחק את מה שיש, והדבק את התוכן של `apps-script/Code.gs`.
4. הוסף קובץ חדש (➕ ← Script) בשם `config` והדבק את `apps-script/config.gs`. עדכן שם שעות, ימים ונוסחים.
5. בחר בפונקציה `setup` ולחץ **הפעלה (Run)**. אשר את ההרשאות. נוצרות לשוניות "הזמנות" ו"משפחות" וטריגר יומי לסיכום.

### 2. וואטסאפ דרך CallMeBot (חינם)
1. שמור באנשי הקשר את המספר של CallMeBot ושלח לו בוואטסאפ את ההודעה שמופיעה באתר שלהם (callmebot.com ← WhatsApp API). המספר וההודעה המדויקים מופיעים שם ומשתנים מדי פעם.
2. תקבל בחזרה **apikey**.
3. ב-Apps Script: **הגדרות הפרויקט (⚙) ← Script properties** והוסף:
   - `CALLMEBOT_PHONE` = המספר שלך, למשל `972501234567`
   - `CALLMEBOT_APIKEY` = המפתח שקיבלת
   - `REPORT_EMAIL` = (רשות) מייל לגיבוי
4. בדיקה: הרץ את `testReportNow` ← אמורה להגיע הודעה לוואטסאפ.

### 3. פרסום הסקריפט ככתובת אינטרנט
1. **פריסה (Deploy) ← פריסה חדשה ← סוג: Web app**.
2. Execute as: **Me**. Who has access: **Anyone**.
3. העתק את הכתובת שמסתיימת ב-`/exec`.
4. אחרי כל שינוי בקוד: **Deploy ← Manage deployments ← עריכה ← Version: New version** (אחרת השינוי לא נכנס לתוקף).

### 4. ימות המשיח
1. פתח מערכת (יש אפשרות חינמית על מספר משותף + שלוחה; מספר ייעודי בתשלום חודשי נמוך — בדוק מחירון עדכני).
2. בשלוחה שתשמש להזמנות, הגדר בקובץ `ext.ini`:
   ```
   type=api
   api_link=https://script.google.com/macros/s/XXXX/exec
   ```
   (`XXXX` — מהכתובת שהעתקת בשלב 3.)
3. **שעות הפעילות מנוהלות בסקריפט** (`config.gs`), אין צורך בהגדרת שעות בימות המשיח.

## שימוש יומיומי
- **לשונית "הזמנות"** — כל השיחות, בזמן אמת.
- **לשונית "משפחות"** — טלפון + שם משפחה. כשמגיע "לא מזוהה" בסיכום: שמע את ההקלטה (בממשק ימות המשיח, בנתיב שמופיע בסיכום) והוסף שורה. מהפעם הבאה המשפחה תזוהה אוטומטית ותופיע בשם.

## דברים שצריך לבדוק בהקמה (לא אומתו מול התיעוד הרשמי)
- **הפניה (redirect):** כתובת Apps Script מחזירה הפניה לכתובת אחרת של גוגל. אם ימות המשיח לא עוקבת אחרי הפניות, השיחה תיפול מיד. במקרה כזה אפשר להוסיף "מתווך" חינמי קטן (למשל Cloudflare Worker) — תגיד לי ואכין.
- **שמות ההגדרות ב-ext.ini** (`type=api`, `api_link`) — לוודא מול מדריך מודול API בפורום ימות המשיח.
- **הקלטה:** הנתיב שבו נשמרת ההקלטה (ברירת מחדל: תיקיית השלוחה, מספור אוטומטי).
- **CallMeBot** הוא שירות חיצוני לא רשמי; אם יפסיק לעבוד — המייל ממשיך כגיבוי.
